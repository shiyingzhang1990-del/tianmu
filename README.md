# 天目 · 4 天明亮眼神速成

一套关于「眼神」的护眼训练系统。围绕眼周肌力、眼球灵活度、聚焦调节、眨眼放松与神采整合，用 4 天循序渐进把「累、干、呆」的眼睛练回水润灵动的状态。

## 功能
- 4 天渐进式训练计划，每天 4 项练习
- 每项带「为什么有效」与分步动作说明
- 追视训练台：光点画十字 / W / 米字 / 圆 / ∞ / 方框 / 远近，3 档速度
- 眨眼节拍器：60 秒「完全眨眼」对抗干眼
- 计时器 + 打卡进度（本地保存）

## 说明
本页面为护眼放松训练参考，不构成医疗建议。若存在斜视、双眼不对焦、视力骤降或持续不适，请及时到眼科就诊。
